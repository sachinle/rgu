# /assets/images/

Place the following image assets in this directory:

## Required Files

| Filename       | Source                        | Notes                                      |
|----------------|-------------------------------|--------------------------------------------|
| logo.png       | /public/logo.png (Next.js)    | RGU logo – used in navbar, hero card, footer |
| bgvideo.mp4    | /public/bgvideo.mp4 (Next.js) | Hero section background video               |

## Notes
- logo.png is displayed on a white-background container in the hero card and footer badge
- bgvideo.mp4 autoplays muted + looped in the hero section
- All other visuals are handled via Tailwind CSS utilities and inline SVG icons
